# OrdenLista Print Service — Descargas

Repositorio **público** para distribuir los instaladores (`.exe`) del **OrdenLista Print Service** sin necesidad de login.

## Última versión
Mira la sección **Releases** (derecha / pestaña) → descarga el `.exe` más reciente, ábrelo y sigue el asistente (se instala por encima de versiones anteriores conservando la configuración).

## Uso
Tras instalar, abre el panel local (http://localhost:8090), pestaña **Configuración**, verifica la impresora y presiona **"Imprimir ticket de prueba"**.
